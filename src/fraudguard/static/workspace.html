A WORKSPACE WITH ACCOUNTABILITY

Welcome back.

Sign in to score transactions, review decisions, and track your models.

Use the username your administrator created, such as naveen. This is not your email address.

An administrator creates accounts. Sessions expire after 30 idle minutes or eight hours total. Refresh clears the browser token; administrator changes require a login within the last 15 minutes.

New here or having trouble signing in?

Accounts are created by an administrator. There is no public sign-up. Ask your administrator for a username and an initial password.

First login: leave the code empty to connect your authenticator. Returning users: enter the current six-digit code, or an unused recovery code. If you lost both, ask your administrator for help.

PROTECT YOUR ACCOUNT

Set up your authenticator

  1. Open your authenticator app and choose Add account → Enter a setup key.
  2. Enter the account and private key below. Choose Time based.
  3. Enter the current six-digit code to verify, then save your recovery codes.

Save your recovery codes

Each code works once if you lose your phone. Save them in your password manager now; they will not be shown again.

Service & model monitoring
Seven-day model cohorts; service latency uses the last five minutes. Alerts require two consecutive watchdog checks, one minute apart.


Controlled model releases
An operator stages a trusted model bundle. Automated quality gates run before a different administrator can approve it. Approved releases can be activated without mixing model versions within a batch.
Model files are executable artifacts. There is deliberately no model-file upload in this web application.


Audit trail
