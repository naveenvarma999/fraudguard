# Documentation map

Start with four maintained guides:

1. [ML evidence](ML_EVIDENCE.md): data, delayed-label features, ablations, calibration and uncertainty.
2. [Lifecycle](LIFECYCLE.md): shared history, late events, retraining, shadow comparison and promotion.
3. [Operations](OPERATIONS.md): Docker, accounts, deployment, backup and recovery.
4. [Verification](VERIFICATION.md): what actually ran locally, on GitHub and on AWS.

The ULB [model card](DATA_AND_MODEL_CARD.md) is a separate baseline. Research notes, decisions and versioned release notes remain for historical traceability; they do not override the current guides or prove that a newer branch is deployed.
